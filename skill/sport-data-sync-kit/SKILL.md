# Sport Data Sync Kit

面向"运动健康数据的接入、清洗、FIT/GPX/TCX 规范化、跨平台同步、时区判据、字段映射、坑位排查"的工作指南。结论以本知识库实测口径为准；与外部规范冲突处标注「本知识库实测」，未闭环项标注「待真机验证」，无证据项标注「未核实」。

## 核心工作流

按顺序执行；每一步先查对应 reference，不要凭印象假设平台行为。

### 1. 接入前核查

- 先确认目标平台在 `references/platforms.md` 中是**已接双向 / 仅上传 / 仅下载 / 半自动 / 实验室**。未接或实验室平台只给公开入口线索，字段、分页、错误码、成功判据一律待真机验证，不得臆造。
- 确认同步方向与所需格式：下载格式与上传格式按平台卡片记录；TCX 不支持温度，GPX 原生无速度字段（见 `references/formats.md`）。
- 跨格式转换前先读格式能力差异表，温度/功率/速度在目标格式无处安放时只能丢弃或降级。

### 2. 凭证 / 鉴权

- 按平台卡片核对鉴权方式：令牌、Cookie sessionid/csrftoken、OAuth2 code→token、个人 API Key Basic、WebView 注入登录态、账号密码换 token。
- 刷新与回写规则分平台处理；401/403 判定、令牌额度、风控间隔见 `references/pitfalls.md`（T3、T20）。
- 凭证存本地键值库，新增凭证键先在凭证表登记；区分凭证库与开关库。

### 3. 列表 / 下载

- 先读平台卡片的列表接口、参数位置（query string / JSON body）、分页契约与成功判据。
- 分页异常（永远只取第一批旧记录）按 `references/pitfalls.md` T1 的直连对照四连法定性：服务端静默忽略参数 ≠ 服务端数据陈旧。
- 下载有效性判据：FIT 长度 ≥14 且 `bytes[8]=='.'`、`bytes[9]=='F'`；短于 100 字节判无效；他人记录 403 按无权限跳过，不计同步失败。
- 校验下载文件：运行 `scripts/check_fit.py` 做魔数与 CRC16 校验（见下）。

### 4. 格式校验与清洗

- 字段号、单位换算、记录层级、脏数据边界见 `references/formats.md`。
- 任何改字节操作（时区平移、坐标纠偏、字段清理）后 **FIT 必须重算文件尾 CRC16**，否则平台判文件无效。
- 迈金（Magene）GPS 坐标是 GCJ-02（火星坐标），上传前纠偏回 WGS-84；黑鸟下载端内部已转 WGS-84，不要二次纠偏。
- 空轨迹 / 0 里程是合法数据（室内台/暂停无 GPS），不要当坏文件丢弃；列表 `extra` 为空、显示 0.0km 只影响展示与文件名，不影响下载字节。

### 5. 时区判定

- 不要靠"local_timestamp 在不在 / 相不相等"单一字段规则判定：同一来源会混用三种文件形态。
- 统一用**锚点法**：以记录真实开始时间（上游列表已解析的 startTimeMs，UTC 正确）为锚对齐，公式与三条护栏（幂等、量程、锚缺失兜底）见 `references/timezone.md`。
- 两套平移逻辑不能同时跑，防止叠加成 ±16h；验证要看目标平台网页端开始时间，不只看接口返回或本地缓存。

### 6. 上传 / 入库

- 按平台卡片的上传路径、表单字段名、成功判据上传；字段名写错（如迈金必须 `jilu0`）服务端不收。
- 异步入库平台（iGP 异步解析、迈金约 15–20s 入库）回 ACK 不等于落库；"显示成功但平台没数据"的 pending 风险见 `references/pitfalls.md` T10。
- 重复活动按平台判重码处理（如行者 9006、Komoot 202），记为跳过而非失败。
- 去重记忆键：`{源short}_{活动id}_to_{目标short}`；success / skipped 分支写记忆键，pending 分支不写。

### 7. 回归验证

- 改动后按 `references/pitfalls.md` 的跨方向回归清单逐条跑；先端到端拿行为矩阵，再反查代码 diff。
- 异步平台上传后等待入库时间再到目标平台核对；时区样本须含当天活动、历史活动、同条重传幂等三类。

## 确定性脚本

- `scripts/check_fit.py`：FIT 魔数、文件头长度、数据区长度与文件尾 CRC16 校验；GPX/TCX 识别并跳过 CRC 校验。纯标准库。

```powershell
python scripts/check_fit.py <file.fit> [file2.fit ...]
```

退出码 0 = 全部通过；1 = 存在非 FIT、魔数不符、长度异常或 CRC 不一致。改过字节的 FIT 报 CRC 不一致时，先重算 CRC 再校验。

## 开源参考使用前必读（易过期信息）

- 参考任何开源项目前，先按 `references/opensource.md` 第一节的"使用前更新步骤"核对仓库主页 README、最近提交、LICENSE；URL 失效按检索关键词重新定位。
- 星数、最近提交、活跃度、许可证均为易过期信息，以检索当日为准；本技能不写死具体数字。许可证只记已核实 SPDX 简称，未核实标「未核实」，禁止据此判定可自由商用。
- 完整 75 条开源清单见本知识库 `docs\02-开源项目对标矩阵.md`；本技能 `opensource.md` 只收高复用度项目。
