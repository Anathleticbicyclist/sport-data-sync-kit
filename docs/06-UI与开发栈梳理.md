## 2. FIT 解析与生成（自研二进制层）

| 模块 | 职责 |
|---|---|
| FIT 二进制构建器 | 手动按 FIT 协议拼装：14 字节文件头 + Definition Message + Data Message + 文件尾 CRC；小端序；FIT 纪元 `1989-12-31T00:00:00Z`（Unix 631065600）；坐标 degree→semicircles 换算。 |
| GPX→FIT 转换器 | 解析 GPX 轨迹点并组装标准 FIT（header + body + bodyCRC）；内置自研 CRC-16/ARC 表，分别重算头部 CRC（前 12 字节）与正文 CRC；含 haversine 距离计算；支持轨迹合并复用转换逻辑。 |
| 设备信息改写 | 可将 FIT 的设备信息改写为常见骑行码表型号，使目标平台接受并计算训练效果；改动 file_id / device_info 消息后须重算文件尾 CRC-16。具体型号映射不列入公开文档。 |
| 坐标修正器（纯 Kotlin） | 迈金 FIT 的 GCJ-02→WGS-84 纠偏；后台任务无 WebView 环境下使用；仅改 record 消息 lat/long 半圆坐标并重算 CRC-16/ARC。 |
| 时间 / 时区修正 | FIT 时区平移与 GPX `<time>` 文本修正；当天 / 历史活动分治处理。 |
| Garmin 官方 FIT SDK | `com.garmin:fit:21.176.0`（依赖已声明）：【未核实】源码中未检索到对应包名的实际 import；当前解析 / 生成仍以自研二进制层为准，该依赖是否被调用需后续核实。 |

## 4. WebView 内执行的 JS 资产

本地 WebView 承载两类桥接资产：一类完成 GPX→FIT 前端转换，另一类执行坐标纠偏；另有同源页面作为特定平台上传回退容器。桥页面与脚本在本地 WebView 内执行，纯 Kotlin 侧有对等实现（坐标纠偏）。资产文件名属内部实现细节，不在公开文档列出。
