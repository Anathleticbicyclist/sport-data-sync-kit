## 一、更新说明（使用前必读）

- **本矩阵核验日期：2026-11-11（Asia/Shanghai）。**
- 本矩阵中的**星数、最近提交时间、活跃度、许可证均属易过期信息**，GitHub 仓库可能改名、转移、归档、删除或更换许可证；表内未写死星数与具体提交哈希，活跃度仅按核验当日是否在近一年内有提交做口径标注。**使用前必须按下方步骤重新检索最新版本与许可证。**
- **许可证口径**：标注 SPDX 简称（MIT / Apache-2.0 / GPL-3.0 / GPL-2.0 / BSD-3-Clause 等）= 已核验仓库 LICENSE 文件或 GitHub 许可证识别结果；标注"未核实"= 仓库根目录未见 LICENSE 文件、GitHub 未识别出 SPDX 许可证，或本次受匿名 API 限额未能打开 LICENSE 原文，**不得据此判定为公有领域或可自由商用**；NOASSERTION = 仓库存在非标准/自定义许可证文本，需打开 LICENSE 原文逐条核对。
- 表内"未核实"格子表示本次检索未取得可核实证据，**严禁据此编造链接、星数、许可证或接口细节**。

### 重新检索操作步骤（URL 失效时照此操作）

1. **打开仓库 URL**：浏览器访问"仓库 URL"列链接，看主页 README、最近提交时间、Releases、LICENSE 文件。
2. **核对许可证**：仓库页右侧栏 → License；或直接打开仓库根目录 `LICENSE` / `LICENSE.txt` / `LICENSE.md` 原文，确认 SPDX 与商用/分发条款。
3. **核对活跃度**：看仓库主页最近提交（commits）、Issue/PR 最近更新时间、是否 archived（已归档）。
4. **URL 失效（404 / 改名 / 转移）时**：用"检索关键词"列在 GitHub 搜索框依次组合搜索 `作者名 + 仓库名`、`仓库名 + 技术栈`、`平台名 + 关键词（同步/导出/fit/gpx/oauth）`；也可在 PyPI / Gitee / Codeberg / GitLab 按包名或作者名检索镜像与 Fork。
5. **接口类信息复核**：鉴权方式、导出格式、同步方向均来自 README 或仓库描述的二手归纳，落地集成前务必重新阅读源码与最新 README，平台私有接口可能随时变更。

### 结论先行

- 本次共覆盖用户点名平台 **21 个**，收录可检索到的开源项目/仓库/依赖 **74 条**（其中含 3 个"未检索到独立开源项目"的占位平台行，不计入项目数）。
- 许可证**已核实 40 条**，**未核实 34 条**（口径见上；统计口径与清单见文末第六节）。
- 国内骑行平台（iGPSPORT / 行者 / 迈金 / 黑鸟 / 百锐腾）的开源参考以**个人逆向脚本/小工具**为主，多数无许可证、私有接口易失效；海外成熟生态以**官方 SDK + 社区解析库 + 自托管仪表盘**为主，许可证与活跃度更稳。
- 跨平台格式事实标准：**GPSBabel**（格式互转）、**gpxpy / tcxreader / python-fitparse / fitdecode**（解析）、**Garmin 官方 FIT SDK**（编解码）。
