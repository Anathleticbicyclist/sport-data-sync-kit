## 三、建议阅读顺序

1. 先读 `03` 回归专题与 `SKILL.md` 工作流，建立「改动后必跑跨方向回归」的整体意识。
2. 接某平台前：`05` 平台卡片 → `04` 格式规范 → `references/platforms.md` 速查。
3. 排查同步失败：`03` 对应坑位 → `01` 方法论 → `references/pitfalls.md`。
4. 检索开源参考：`02` 全量矩阵 → `references/opensource.md` 高复用条目；引用前按「使用前更新步骤」重新核对 README 与 LICENSE。
